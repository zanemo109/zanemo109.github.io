Part 1.1: Implementing the Forward Process

The Noising Process

The forward process is a key component of diffusion models. Given a clean image x₀, we add Gaussian noise to obtain progressively noisier versions x_t. The amount of noise is controlled by the timestep t and noise schedule parameters α̅_t (alphas_cumprod).

Forward Process: x_t = √(α̅_t) · x₀ + √(1 - α̅_t) · ε, where ε ~ N(0, I)

I implemented the forward(im, t) function and applied it to the Campanile test image at timesteps t = [250, 500, 750]. As t increases, more noise is added, eventually obscuring the original image.

Using the Pretrained UNet

Now I use the pretrained DeepFloyd UNet to estimate the noise in each image. The UNet takes the noisy image and timestep as input and predicts the noise ε that was added. By rearranging the forward process equation, we can recover an estimate of the clean image x₀.

Noise Removal: x̂₀ = (x_t - √(1 - α̅_t) · ε̂) / √(α̅_t)

Part 1.4: Iterative Denoising

The DDPM Sampling Loop

Instead of trying to denoise in a single step, diffusion models are designed to denoise iteratively. Starting from noisy image x_t, we take small denoising steps to get x_{t'} where t' < t, eventually arriving at x_0. This allows the model to gradually refine its estimate.

I implemented iterative_denoise() using strided timesteps starting at 990 with stride 30, giving steps [990, 960, 930, ..., 30, 0]. At each step, we predict noise, estimate x_0, then compute x_{t'} as a linear interpolation between signal and noise with added variance.

Part 1.6: Classifier-Free Guidance (CFG)

Improving Sample Quality

Classifier-Free Guidance (CFG) is a technique to improve image quality by trading off diversity. We compute both conditional (ε_c) and unconditional (ε_u) noise estimates, then extrapolate away from the unconditional prediction.

CFG: ε = ε_u + γ · (ε_c - ε_u)

where γ controls guidance strength (γ = 7 used here)

CFG Samples (γ = 7)

Five images generated with Classifier-Free Guidance (γ = 7). The results are significantly sharper and more coherent than without CFG.

Part 1.7.2: Inpainting

Inpainting uses the same diffusion process but constrains regions outside a mask to match the original image at each denoising step. This allows us to fill in missing regions while keeping the rest intact.

Inpainting: x_t = m ⊙ x_t + (1 - m) ⊙ forward(x₀, t)

where m is the binary mask (1 = region to edit)

Part 1.8: Visual Anagrams

Creating Optical Illusions

Visual anagrams are images that look like one thing when viewed normally but reveal a different image when flipped upside down. We create these by denoising with two prompts simultaneously — one for the upright view and one for the flipped view — and averaging the noise estimates.

Visual Anagram: ε = (ε₁ + flip(UNet(flip(x_t), t, p₂))) / 2

where ε₁ = UNet(x_t, t, p₁) and p₁, p₂ are different prompts

Part 1.9: Hybrid Images

Frequency-Based Image Fusion

Building on the hybrid image technique from Project 2, we can create diffusion-based hybrid images using Factorized Diffusion. We combine low frequencies from one noise estimate with high frequencies from another, creating images that appear different at different viewing distances.

Hybrid: ε = f_lowpass(ε₁) + f_highpass(ε₂)

where ε₁, ε₂ are noise estimates from different prompts

Part B: Flow Matching from Scratch

In Part B, I trained my own flow matching model on MNIST from scratch. This involved building a UNet architecture, implementing both single-step and iterative denoising, and adding time and class conditioning to enable controlled generation of handwritten digits.

Part B 1.1: Implementing the UNet

UNet Architecture

I implemented a UNet architecture for denoising, consisting of downsampling and upsampling blocks with skip connections. The network uses Conv, DownConv, UpConv, Flatten, and Unflatten operations to process images at multiple resolutions while maintaining spatial information through skip connections.

The UNet takes a noisy image as input and outputs a denoised estimate. The architecture uses a hidden dimension D = 128 for the single-step denoiser, with the following key components:

  • Conv: Convolutional layer that maintains image resolution, only changing channels
  • DownConv: Downsamples the tensor by 2× using strided convolution
  • UpConv: Upsamples the tensor by 2× using transposed convolution
  • Flatten: Average pooling to reduce 7×7 spatial dimensions to 1×1
  • Unflatten: Convolution to upsample from 1×1 back to 7×7

Part B 1.2: Using the UNet to Train a Denoiser

The Noising Process

To train the denoiser, I generate training pairs (z, x) where x is a clean MNIST digit and z is a noisy version created by: z = x + σ · ε, where ε ~ N(0, I). Below is a visualization of the noising process at different σ values.

Analysis

Observed Patterns: The outputs tend to look like blurry, averaged versions of digits rather than crisp, distinct numbers. This is because with MSE loss, the model learns to predict the point that minimizes the sum of squared distances to all training examples — essentially the centroid or mean of the training distribution.

Why This Happens: When given pure noise with no signal, the optimal prediction under L2 loss is the average of all possible outputs. Since MNIST contains digits 0-9, the model outputs a blurry superposition of all digits, kind of resembling an "8". This demonstrates why single-step denoising fails for generative tasks — we need iterative denoising (flow matching) to generate distinct samples.

Part B 2.1: Adding Time Conditioning to UNet

Time-Conditioned Architecture

For flow matching, we need to condition the UNet on the timestep t to tell it how noisy the input is. I added FCBlocks (fully-connected blocks) to inject the time conditioning signal into the UNet at strategic locations (after unflatten and after the first upsampling block).

Flow matching interpolation: x_t = (1 - t) · x₁ + t · x₀

where x₁ ~ N(0, I) is noise and x₀ is a clean image

The model learns to predict the flow v = x₀ - x₁, which describes how to move from noise to clean data.

Part B 2.2: Training the Time-Conditioned UNet

Training Configuration

  • Dataset: MNIST training set
  • Batch Size: 64
  • Epochs: 10
  • Hidden Dimension: D = 64
  • Optimizer: Adam with initial learning rate 1e-2

Part B 2.4-2.5: Adding Class Conditioning

Class-Conditioned Architecture

To gain control over which digit is generated, I added class conditioning to the UNet. The class label (0-9) is encoded as a one-hot vector and injected via additional FCBlocks. During training, 10% of the time the class conditioning is dropped (set to zero) to enable classifier-free guidance during sampling.

Modulated features: unflatten = c₁ · unflatten + t₁

where c₁ = FCBlock(class) and t₁ = FCBlock(time)

Training Loss Curve

Training loss curve for the class-conditioned UNet. The model converges faster than the time-only version due to the additional conditioning signal.

Part B 2.6: Sampling from the Class-Conditioned UNet

Classifier-Free Guidance Sampling

With the class-conditioned model, I use classifier-free guidance (CFG) with γ = 5 during sampling. This involves computing both conditional and unconditional flow predictions and extrapolating toward the conditional direction.

CFG: v = v_uncond + γ · (v_cond - v_uncond)

Training Without the Learning Rate Scheduler

The exponential learning rate scheduler previously decayed the learning rate by γ = 0.1^(1/10) per epoch. To train without a scheduler, I made the following adjustment:

  • Lower Base Learning Rate: Reduced from 1e-2 to 2e-3 to avoid instability at later training stages when the scheduled LR would normally be smaller

Training without a scheduler converges slightly more slowly early on, but remains stable and achieves comparable final performance. This demonstrates that careful tuning of a constant learning rate can substitute for explicit scheduling in this task.
